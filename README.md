# Dance Event API

Сервис на FastAPI для ведение списка занятий по танцам в студии.
Позволяет создавать занятия, просматривать список  c фильтрацией по дате и стилю танца, добавлять учеников и изменять их данные.

Приложение предназначено для администраторов танцевальной студии и преподавателей, которым нужно создавать расписание занятий и записывать в них учеников.

1. Создание окружения и установка зависимостей

```bash
git clone https://github.com/Anna777o/dance-events-api.git
cd dance-events-api

python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements-dev.txt
```
2. Запуск приложения

Режим разработки с автоперезагрузкой:

```bash
uvicorn app_final:app --reload
```

После запуска необходимо открыть Swagger:

http://127.0.0.1:8000/docs

Остановить приложение: `Control + C` в терминале.

3. Переменные окружения

Необходимо скопировать шаблон `.env.example` в `.env`:

```bash
cp .env.example .env
```
|---|---|---|
| Переменная | По умолчанию | Назначение |
| `APP_VERSION` | `1.0.0` | Версия приложения, отдаётся в `/version` |
| `DEFAULT_STUDIO` | `Зал №1` | Зал по умолчанию, если не указан при создании занятия |
| `LOG_LEVEL` | `INFO` | Уровень логирования (DEBUG, INFO, WARNING, ERROR) |

Файл `.env` не коммитится (он в `.gitignore`).


4. Запуск тестов

```bash
python -m pytest -v
```

Ожидаемый результат — 6 passed.

5. Проверка /health и /version

```bash
curl http://127.0.0.1:8000/health
```

Ожидаемый ответ:

```json
{"status": "ok"}
```

```bash
curl http://127.0.0.1:8000/version
```

Ожидаемый ответ:

```json
{"version": "1.0.0"}
```

6. Логи

Логи выводятся в стандартный поток вывода (stdout) того терминала,
в котором запущен `uvicorn`. Уровень регулируется переменной `LOG_LEVEL`.

Что логируется:

- запуск приложения и его версия;
- значение `DEFAULT_STUDIO` при старте;
- создание занятия;
- добавление ученика;
- изменение данных ученика;
- предупреждения при ошибках (404 - не найдено, 400 - превышен лимит учеников).

7. Обычный режим работы (без `--reload`):

```bash
uvicorn app_final:app --host 0.0.0.0 --port 8000
```
